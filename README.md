## Important Notice ##

If you know how to build this into a Plugin, feel free to use it. However, please keep in mind that it may throw errors or behave unexpectedly due to missing dependencies.

### About This Project ###
* **Core Module Only:** This repository contains the Core module with various features for a Minecraft plugin.
* **Part of a Larger Ecosystem:** Some functions will not work properly on their own because this is just one piece of the full **`rpgcore`** ecosystem, which also includes:
  * `rpgquest`
  * `rpgdens`
  * `party`
  * `guild`

### Usage & Modification ###
If you know how to pull the source code and modify it to fit your own server or project, **you are completely free to use and customize it!**
